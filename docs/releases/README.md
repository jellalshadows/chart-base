# Release records

One record per release: how the release was made, the decisions and rulings of its execution with their reasons and
their cost if wrong, the deviations from its plan, every review finding and its resolution, the measurements that
changed a decision, what was not verified, and, after the merge, its pull request, CI, Release PR and published
digest. The [changelog](../../CHANGELOG.md) lists what each release changed; a record says how and why.
