# 1.0.0: the contract binds

1.0.0 changes no values, no template and no rendered object. It declares the contract of
[ADR-0058](../adr/0058-the-1-0-contract-and-how-it-stays-frozen.md) binding: from this release on, a breaking change
(`feat!:`, `fix!:`) is a major. The selector labels, the object names and the values keys change only in a major, and
CI fails a pull request that removes or renames a values key unless it is marked breaking.

## The gate: a validation campaign on the published 0.12.0

The roadmap's last criterion ([1.0.0 criteria](../roadmap.md#100-criteria)) was a validation campaign on kind against
the published 0.12.0, with any defect shipped first as a 0.12.x.

- **Cells:** four, Kubernetes 1.33.12 and 1.37.0, each with Helm 3.22.0 and 4.3.0.
- **Where:** kind in Docker Engine 29.10.0 inside WSL2, on 2026-11-17.
- **Candidate:** `oci://ghcr.io/jellalshadows/charts/chart-base:0.12.0`
  (`sha256:1934c306c6716c950a201d297d632559ef754d83528049100816d987a748142a`).

**The claim-check failures on Helm 3.22 were in `e2e.sh`, not in the chart.**

- **The race:** the check read `readyReplicas` right after an upgrade with `maxSurge: 0, maxUnavailable: 1` on one
  replica. Helm 3's legacy `--wait` counts that Deployment ready at zero Ready pods. CI runs e2e on Helm 4.3 only.
- **The fix:** #31 waits for the rollout and adds a note on Helm 3's `--wait` to the consuming guide.
- **With the fix:** the whole `e2e.sh` passed on both Helm 3 cells. So did the upgrade path from 0.11.0: 43 checks,
  every Deployment rolled exactly once and kept its uids and selectors.
- **No 0.12.x was needed.**

**C6 also settled the known gap of [ADR-0046](../adr/0046-configfiles-mountpath-compared-normalized-rendered-as-written.md):**
ancestors of the token directory stay allowed
([ADR-0060](../adr/0060-the-main-container-takes-the-entries-checks-and-one-token-directory-rule.md)).

**The environment, and how it differs from CI:**

- **CNI:** the WSL2 kernel has no nftables queue expression, so kindnet does not enforce NetworkPolicy there. The
  campaign ran Calico v3.33.0; CI keeps kindnet.
- **Recipe images:** the README recipes' fictional images ran as agnhost stand-ins, so an image's own reading of its
  files is not exercised.
